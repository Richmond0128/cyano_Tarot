# 金錢卦銅錢圖片素材：天錢／地錢

來源：使用者提供的實物照片（八卦錢，已裁切成單面、以 Lanczos 內插放大解析度；非 AI 超解析，僅供排版參考，正式上線前建議用更高畫質的實拍或去背素材替換）。

## 分類與用途（依使用者說明）

- **地錢**（顏色較暗、青銅色）：**白天（06:00–18:00）**使用。
  - 正面：八卦面（乾坎艮震巽離坤兌＋卦畫），代表陽。
  - 背面：十二生肖（鳥蟲篆／花押字體）。
- **天錢**（顏色較亮、金色）：**晚上（18:00–06:00，跨午夜）**使用。
  - 正面：八卦面，與地錢正面同款，代表陽。
  - 背面：天師符咒文，內容為「雷霆役召◯◯鬼降精、斬妖辟邪清◯◯、太上老君急如律敕」一類道教鎮煞符文。

## 網站功能規則

- **自動判斷**：以使用者本機系統時間為準，06:00（含）～18:00（不含）用「地錢」，18:00（含）～隔日 06:00（不含）用「天錢」。
- **手動切換**：提供切換選項（如同塔羅牌背設計切換），讓使用者可自行覆蓋自動偵測結果，選用另一款銅錢外觀；使用者離開/重新整理頁面後，是否記住手動選擇或每次都重新依時間判斷，由實作時決定。
- **正／反面**：起卦動畫中銅錢翻轉顯示用。兩種錢的正面（八卦面）設計相同、皆代表陽（計分 3）；背面（地錢十二生肖／天錢符咒）皆代表陰（計分 2）。日夜切換只影響銅錢的「外觀樣式」（換成天錢或地錢的圖），不影響起卦的陰陽計分邏輯本身。
